16. ANIMATION AND INTERACTION SYSTEM
==================================================

Animations are an important part of
the website experience.

Use vanilla JavaScript and CSS.

Do not introduce React or animation frameworks.

PREFERRED TECHNIQUES:

- CSS transitions
- CSS keyframes
- IntersectionObserver
- requestAnimationFrame where appropriate
- Native browser APIs

ANIMATION PRINCIPLES:

Smooth.
Subtle.
Purposeful.
Responsive.
Accessible.
Performance-conscious.

SCROLL REVEALS:

Elements may fade and move upward
when entering the viewport.

Example:

Initial:
opacity: 0
transform: translateY(20px)

Visible:
opacity: 1
transform: translateY(0)

Duration:
500ms to 700ms.

Use IntersectionObserver.

HOVER EFFECTS:

Buttons:
180ms to 250ms.

Cards:
250ms to 350ms.

Navigation:
180ms to 250ms.

IMAGE REVEALS:

Use subtle opacity and transform animations.

Avoid excessive zooming.

SMOOTH SCROLLING:

Use CSS scroll-behavior where appropriate.

Respect reduced-motion settings.

IMPORTANT:

The website must remain usable if JavaScript
is disabled or fails to load.

Do not hide essential content permanently
behind JavaScript-dependent animations.

Respect prefers-reduced-motion.

Avoid excessive parallax and scroll hijacking.
